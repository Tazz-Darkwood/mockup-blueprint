Where every font file in this folder came from (checked 2026-10-07)

All fourteen files are Google Fonts families, downloaded from Fontsource's copy of them
(https://cdn.jsdelivr.net/fontsource/fonts/<id>/<file>). Fontsource packages the Google Fonts
collection for self-hosting; its API lists each of these with "type": "google",
"source": "https://github.com/google/fonts" and "license": "OFL-1.1"
(https://api.fontsource.org/v1/fonts/<id>). Each file below except one was compared byte for byte
(SHA-1) with a fresh download from that address on 2026-10-07 and is identical.
Every family is under the SIL Open Font License 1.1; its licence file is beside it (OFL-*.txt).

The one modified file. The Fraunces italic is used only for a few words of accent, always soft and
large, so it was cut down with fontTools 4.66 (Fraunces has no Reserved Font Name, so a modified copy
may keep its name under the OFL):
    fonttools varLib.instancer fraunces-latin-full-italic.woff2 WONK=0 SOFT=100 opsz=144 wght=300:500
then saved as woff2. 149720 -> 40376 bytes. It cannot show SOFT or opsz changing: pinned.

Not subset further. Fontsource's latin files already hold only the latin block (U+0000-00FF and
common punctuation); cutting them to Basic Latin plus Latin-1 saved only 2 to 9 per cent
(Karla 32116 -> 29708, Caveat 74932 -> 72708), and an unmodified file can be checked against its
source by its hash. Three families have Reserved Font Names (Source, Pirata, Cinzel): under the OFL
FAQ (2.6) subsetting is modification, and a modified copy may not keep a reserved name, so those
three must never be subset or instanced here.
