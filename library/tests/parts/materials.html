Materials: the layers

Every option of every layer, then every starting point, each on a light page and a dark one. Each swatch is one sheet with a heading, a line of text, a line of soft text and a button, so the material is the only thing that changes. Built from the shared colour names only: no sheet has a border (that is frames) and every shadow is the light part's.
