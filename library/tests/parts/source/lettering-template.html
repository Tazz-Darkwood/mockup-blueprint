Lettering: the layers

Every option of every layer, then every starting point, each on a light page and on a dark one. Each swatch holds the same things: a label, a heading set in the display face, a sheet with a paragraph in the reading face, a figure, and a button, so the one layer is the only thing that changes. The line at the top of each names the faces. On the dark page the reading text is set a little lighter (400 down to 370), because light letters on a dark ground look heavier.
