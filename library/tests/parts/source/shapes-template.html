Corners and shapes: the layers

Four layers, each switched on its own: the corners of every box, the outline of buttons and fields, the shape of tags and badges, and the shape a picture is cut to. Every option is shown on a light page (left) and the same CSS on a dark one (right). Each swatch holds the same things, so only the shapes change: a sheet, a picture, two labels, a field (drawn as if it had the keyboard, so its focus ring shows), the main button, a tick box and a round choice. Colour, borders, shadows and type are fixed, borrowed from the other parts.
